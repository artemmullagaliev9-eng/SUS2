NEXSUS DLC — початковий Android-проєкт
=======================================

ЩО Є В ЦІЙ ВЕРСІЇ
- Плаваюча панель поверх інших застосунків.
- Приціл по центру екрана: перемикач, форма, розмір і кілька кольорів.
- FPS-бейдж із ручним числом (це НЕ справжній FPS гри).
- Стилі: чорний/фіолетовий, білий, Halloween, новорічний.
- Налаштування зберігаються в SharedPreferences: після закриття/перезапуску вони залишаються.
- Android сам прибере їх після очищення даних застосунку або видалення застосунку.

ВАЖЛИВО
Цей проєкт створює тільки інформаційне/візуальне плаваюче меню.
Він не змінює Standoff 2, не дає переваг у механіці гри, не показує ворогів
крізь стіни та не змінює патрони, здоров'я чи FPS гри.
Число FPS вводиться вручну й лише відображається.

ЯК ЗІБРАТИ APK НА НОРМАЛЬНОМУ КОМП'ЮТЕРІ
1. Встанови Android Studio з офіційного сайту:
   https://developer.android.com/studio
2. Відкрий Android Studio -> Open.
3. Вибери розпаковану папку NEXSUS_DLC_Android (де лежить settings.gradle).
4. Дочекайся Gradle Sync. Якщо попросить встановити Android SDK Platform 35,
   погодься. Потрібне підключення до інтернету.
5. Для тесту під'єднай Android-телефон USB-кабелем, увімкни USB debugging
   у Developer options, потім натисни Run.
6. Щоб отримати APK: Build -> Build Bundle(s) / APK(s) -> Build APK(s).
7. Після завершення натисни Locate у повідомленні Android Studio.
   APK зазвичай буде в app/build/outputs/apk/debug/app-debug.apk.

ЯК ЗАПУСТИТИ НА ТЕЛЕФОНІ
1. Встанови APK.
2. Відкрий NEXSUS DLC.
3. Натисни «Дозволити показ поверх інших програм» і ввімкни дозвіл.
4. Повернись у застосунок і натисни «Запустити плаваюче меню».
5. Перемкнися в Standoff 2. Для завершення повернись у застосунок
   і натисни «Зупинити плаваюче меню».

ПРИМІТКИ
- Android може вимагати дозвіл на сповіщення для постійного повідомлення сервісу.
- На деяких оболонках (зокрема Infinix/XOS) треба дозволити автозапуск
  і роботу у фоні, якщо система зупиняє сервіс.
- Якщо Gradle Sync не проходить, перевір JDK 17 (Android Studio зазвичай
  постачає власний JBR) та підключення до інтернету.
- Це вихідний Android-проєкт, не готовий APK.
